# datasource-mat-material-x-sample

An engine project that carries the standard `.mtlx` material libraries and sample assets for trying `.mtlx` materials in a scene.

## What it is for

It holds the standard `.mtlx` data libraries, sample geometry and textures, and a scene that applies `.mtlx` materials to them, as a fixture for material import work.

## Build and run

Open `project.godot` in the engine and run `materialx_samples/scenes/material_x_sample.tscn`.
